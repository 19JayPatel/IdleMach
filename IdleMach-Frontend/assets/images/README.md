# Images

Homepage illustrations and future approved manufacturing imagery.

## Current files

These are original SVG illustrations created for the Phase 2.1 homepage and
reused on the Phase 2.2 Explore Machines page and Phase 2.3 Machine Details
gallery. They are illustrations, not photographs, and are not presented as
images of specific real machines or listings.

| File                     | Use                                              | ViewBox   |
| ------------------------ | ------------------------------------------------ | --------- |
| `hero-workshop.svg`      | Hero: CNC workshop and weekly capacity board     | 880 × 720 |
| `owner-capacity.svg`     | For machine owners: capacity plan                | 720 × 560 |
| `buyer-part.svg`         | For buyers: technical drawing and capacity search| 720 × 560 |
| `machine-turning.svg`    | Sample listing: CNC turning machine              | 640 × 400 |
| `machine-milling.svg`    | Sample listing: vertical machining centre        | 640 × 400 |
| `machine-fabrication.svg`| Sample listing: hydraulic press brake            | 640 × 400 |

Each file uses an inline `<title>` and `<desc>` for its own SVG context. The
`<img>` elements on the homepage and Explore Machines page also provide their
own `alt` text. All listing images use a fixed aspect ratio so cards and figures
stay aligned.

The three machine illustrations are used only beside records labelled
**Sample listing** / **Sample data** / **Demo data** and in the sample Machine
Details gallery. Do not reuse them in a way that implies they show a real
customer machine.

Each sample record provides one illustration. The Machine Details gallery
supports multiple images and thumbnail selection, but no additional approved
machine images exist yet, so the thumbnail strip is not shown for the current
records.

## Guidance for later phases

- Use only images the project has permission to publish.
- Keep file names descriptive and lowercase, for example
  `turning-machine-01.webp`.
- Prefer WebP or optimised JPEG for photographs.
- Provide meaningful `alt` text for informative images; use `alt=""` for purely
  decorative images.
- Do not imply that an image shows a specific real listing unless it does.
- Maintain the existing image aspect ratios when replacing an illustration.
- Keep sample records clearly labelled when real listings are unavailable.
