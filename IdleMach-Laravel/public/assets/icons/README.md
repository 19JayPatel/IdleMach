# Icons

Current files:

- `favicon.svg` — **provisional** capacity-bar mark used as the favicon and the
  temporary header/footer brand mark.

This is not an approved IdleMach logo. It exists only so the prototype has a
consistent temporary mark. Replace it when the brand identity is approved, and
update the two references in `index.html` and `styleguide.html` if the file name
changes.

Interface icons come from Font Awesome 6.7.2 in `assets/vendor/fontawesome/`.
Decorative icons use `aria-hidden="true"`; icon-only controls need an
`aria-label`.
